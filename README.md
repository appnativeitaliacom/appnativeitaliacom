# AppNative Italia

Sviluppiamo strumenti digitali per studi professionali, centri e piccole attività in Italia. Parli direttamente con chi sviluppa, e sai subito da che cifra si parte.

## Che cosa facciamo

| Servizio | In breve |
|---|---|
| [Gestionali su misura](https://appnativeitalia.com/gestionali/) | Prenotazioni, pratiche, scadenze, ordini: costruiti su come lavori, in PHP e Laravel |
| [WordPress](https://appnativeitalia.com/wordpress/) | Assistenza, manutenzione, siti lenti o violati, WooCommerce |
| [Plugin WordPress](https://appnativeitalia.com/plugin-wordpress/) | Funzioni nuove, modifiche e collegamenti con altri programmi |
| [App per iPhone e Android](https://appnativeitalia.com/app/) | Un solo sviluppo con React Native ed Expo, pubblicazione sugli store |
| [Siti web](https://appnativeitalia.com/siti-web/) | Siti professionali e web app, online anche in una settimana |
| [Server e VPS](https://appnativeitalia.com/server/) | Gestione, sicurezza, copie, trasferimenti |

## Prezzi dichiarati

I prezzi di partenza sono pubblici: [listino](https://appnativeitalia.com/costi/) e [preventivo online](https://appnativeitalia.com/preventivo/), che calcola la cifra minima mentre rispondi.
